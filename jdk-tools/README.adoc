Subdirectory: `docs`

CAUTION: The sources themselves contain no Javadoc. Instead, they have regular comments: transform them into proper Javadoc.

== Multi-root project (10 points)

Subdirectory: `multi`

Create two scripts: `build.sh` and `run.sh`.

build.sh {fr|es|it} <OUTPUT_DIR>::
Compiles the specified subroot (`france`, `spain` or `italy`) and puts the result into the `OUTPUT_DIR`.

TIP: If you want to use `**` glob pattern, add `shopt -s globstar` to your script.

run.sh <BUILD_DIRS>...::
Runs `Bar.java` from the `bar` directory. The `OUTPUT_DIR`{empty}s from the `build.sh` are passed as CL-options. _Do not compile `Bar.java`: run it directly!_

== Jars (10 points)

Subdirectory: `multi`

Create a `jar.sh` script which produces three jars: `fr.jar`, `es.jar`, `it.jar`. Each jar must contain its package only and be executable (use `Runner` class). The jars must be put to the directory provided as `$1`.

== More jars (10 points)

Subdirectory: `multi`

Create an `entrypoint.sh` script which produces `main.jar` file. This jar must be executable and contain `Bar.class` only. The jar file must be configured so that it can be executed with `java -jar` when `fr.jar`, `es.jar` and `it.jar` are placed next to it.

TIP: During the seminar we had a problem with running `java -cp .. -jar ..`. The command failed due to the fact that `java` ignores `-cp` option when `-jar` is provided. To fix this, you must introduce the required classpath within the jar's manifest.

== AOT cache (10 points)

Java 24 and 25 introduced an interesting feature: AOT cache.
It helps to reduce the startup time and still be able to use JIT compiler. One of the most time-consuming actions during the startup is dynamic class loading. Spring framework face this problem especially: it loads dozens of classes with reflection. This feature may help with this problem.

To understand how to use the feature read https://openjdk.org/jeps/514[JEP 514].

You have to create two files: `gen_aot.sh` and `run.sh`.

gen_aot.sh::
Generates cache. To start the app, you have to generate the class which are to be loaded later. Run `Gen.java` to create them. After the classes are generated, run the `main` method from the `Enter` class and collect the AOT cache.

run.sh::
Runs the `main` method from the `Enter` class, using the collected AOT cache before.
